How I think

How I build systems

Core mental models, development principles, and execution standards I adhere to as a young builder

Learn by breaking things

1m ago

The fastest way to truly master an abstraction, compiler, or runtime is to construct a minimal, working version of it from scratch. Understanding the underlying engine beats reading abstract theory every time.

Deterministic AST over Regex

8m ago

Never parse, refactor, or validate source code with brittle regular expressions. Abstract Syntax Trees (AST) and token boundaries guarantee zero unexpected side effects and mathematical predictability.

Zero-slop & typed contracts

15m ago

Enforce strict boundary validation, explicit typed error propagation, and zero silent failures. Write software that fails fast and reports root causes rather than silently swallowing exceptions.

Building with purpose at 16

24m ago

Age is just a number. Real engineering value comes from shipping functional, reliable tools that solve actual bottlenecks. Curiosity, consistency, and clean code outperform hype.
